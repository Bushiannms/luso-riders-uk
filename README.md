# Luso Riders UK

Jogo idle do clube de motas Luso Riders UK, com o presidente Marco Machado.

- O jogo está em `www/index.html`.
- Cada alteração no ramo `main` compila um APK de teste em **Actions → Compilar APK → luso-riders-apk**.
- Com o GitHub Pages ativo (Settings → Pages → Source: GitHub Actions), o jogo fica jogável no browser.
